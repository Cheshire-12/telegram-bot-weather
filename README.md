# Telegram-бот погоды

Телеграм-бот, который показывает текущую погоду: выберите город из списка или отправьте свою геолокацию — бот вернёт температуру и состояние погоды.

## Возможности

- Мультиязычность (русский, английский, японский): язык подхватывается автоматически из языка устройства/аккаунта (`language_code`)
- Inline-клавиатура с пагинацией (~46 городов): российские города, популярные мировые столицы и города Японии
- Кнопка «📍 Моя локация (GPS)» — погода по переданной геолокации
- Кнопки «◀️ ▶️» для перелистывания списка городов и индикатор страницы
- Кнопка «⬅️ Назад к выбору» для возврата в меню (на ту же страницу)
- Состояние погоды с эмодзи (☀️, 🌧, ❄️ и др.) и температура в °C
- Понятные ответы для любых сообщений (стикеры, фото, неизвестный текст)

## Стек

- **Python 3.12**
- **pyTelegramBotAPI (telebot)** — работа с Telegram Bot API
- **OpenWeatherMap** — источник данных о погоде
- **requests** — HTTP-клиент
- **python-dotenv** — загрузка ключей из `.env`
- **uv** — менеджер пакетов и виртуального окружения
- **pytest** — тестирование (dev-зависимость)
- **i18n** - локализцаия на 3 языка (ru, en, jap)

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)
- make
- Ключи: токен Telegram-бота и ключ OpenWeatherMap

## Установка

```bash
make setup
```

Цель `setup` выполнит `uv sync` (создаст виртуальное окружение и установит зависимости) и создаст файл `.env` из шаблона `.env.example`, если его ещё нет.

Затем заполните `.env`:

```env
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
OPENWEATHER_API_KEY=your_openweather_api_key
```

- `TELEGRAM_BOT_TOKEN` — получить у [@BotFather](https://t.me/BotFather) в Telegram
- `OPENWEATHER_API_KEY` — получить на [openweathermap.org](https://openweathermap.org/) (бесплатная регистрация; ключ активируется до 2 часов)

Файл `.env` находится в `.gitignore` — ключи не попадают в репозиторий.

## Использование

### Запуск бота

```bash
make start
```

Эквивалент: `uv run bot.py`. Бот запускает long-polling и готов к работе.

### Тесты

```bash
make test
```

Эквивалент: `uv run pytest`. Покрывают логику погоды (маппинг условий на 3 языках, ошибки API), клавиатуры (пагинация, локализация), обработчики команд и валидность городов.

## Цели Makefile

| Цель  | Команда                | Описание                                   |
|-------|------------------------|--------------------------------------------|
| setup | `uv sync` + `.env`     | Установка зависимостей и подготовка конфига |
| start | `uv run bot.py`        | Запуск бота                                |
| test  | `uv run pytest`        | Запуск тестов                              |

## Структура проекта

```
telegram-bot-weather/
├── bot.py          # точка входа: запуск бота
├── config.py       # загрузка ключей, экземпляр бота
├── i18n.py         # локализация (ru/en/ja): строки UI, маппинг условий погоды
├── weather.py      # запросы к OpenWeatherMap, маппинг условий погоды
├── keyboards.py    # inline-клавиатуры (пагинация городов) и меню
├── handlers.py     # обработчики команд, колбэков и сообщений
├── cities.py       # список городов с координатами и именами на 3 языках
├── tests/          # тесты pytest
├── pyproject.toml  # зависимости и настройки
└── Makefile        # цели setup / start / test
```

## Безопасность

- Ключи хранятся только в `.env` и в репозиторий не попадают
- В логах не выводится сам ключ и URL запроса с ним — при ошибке API печатается только HTTP-статус
